# Thirumal Vel Enterprise (Kedai Hardware)

High-performance, Apple HIG-inspired bilingual website for **Thirumal Vel Enterprise**, a hardware store and direct building materials supplier in Bandar Seri Coalfields, Selangor.

## Features
- **Strict White Theme / Light Mode**: Clean `#FFFFFF` canvas, tiered off-white structural surfaces, subtle neutral hairline borders, and zero AI-slop aesthetics.
- **Bilingual English & Bahasa Melayu**: Instant client-side switching with persistence.
- **Master Product Catalogue**: Filterable by categories (Building Materials, Piping & Plumbing, Tools, Cutting Tools, Waterproofing, Kitchen & Bath, Paint) with search and WhatsApp enquiry integration.
- **24/7 Store Shifts & Direct Assistance**: Day shifts with Mr. Saravanan (019-914 4743) and after-hours on-call emergency site supply with Mr. Hari (016-615 9365).
- **Interactive Location & Directions**: Real Google Maps embed, Waze shortcut, and one-click copy address.
- **Fully Responsive**: Mobile (360-480px), tablet (768-1024px), laptop, and ultra-wide desktop layouts.

## Getting Started

```bash
# Inside thirumalvel folder:
npm install
npm run dev

# Or to build for production:
npm run build
```
